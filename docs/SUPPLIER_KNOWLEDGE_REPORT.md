# 仕入先情報の登録・回答テスト

2026年10月3日。対象はホームページのお客様向けチャット。仕入・外注先の社名・HP・取引口座は非公開とし、取扱分野の案内と担当者への相談に使用する。

## 登録した情報

- 提供されたExcelの「仕入」シートから、取扱い品の記載された41行を抽出し、45種類の案内用分野に整理した。
- 社名・元の取扱い品・HP・シート名・行番号は社内データに保存。公開APIには返さない。売買金額やその他の台帳明細は取り込まない。
- 「全取引先ではない」「主要な取引先に限定」「掲載会社は取引口座あり」という提供者の補足は情報源の社内メモに保持する。
- Excel内のURLは管理者確認用に保存する。HP本文は取得していない。取引口座の存在を個別商品の販売承認・価格・在庫・納期の根拠にしない。
- ローカルのアプリ用DBに登録済み。公開環境へのデプロイは行っていない。

## 管理画面での操作

1. `/admin?tab=sources` の「情報源を追加」を開く。
2. 種類に「仕入・外注先一覧（Excel）」を選び、必要なら資料の補足を入力する。資料は社内のみとして保存される。
3. 「取込」からExcelを選ぶ。会社名・主要取扱製品・HPと「回答に使う分野」のプレビューを確認する。
4. 「回答に使う分野を確認しました」をチェックして取り込む。未承認で保存した場合はチャットの根拠に使用しない。
5. 「編集」の「承認済みの取扱分野をチャットの回答に使う」をONにする。ONにしても未承認の情報は使用されない。
6. 「登録内容」で保存内容を確認できる。利用停止は回答利用のチェックを外すか情報源を無効化する。再取得した会話履歴も現在の設定に合わせて再構成する。

再取込は同じ情報源の一覧全体を置き換える。削除された行が残り続けたり、同じ行が重複登録されたりしない。資料の種類は登録後に他形式へ変更できない。

## 回答例

質問: パッキンを扱っていますか？

> 「パッキン」の分野についてご相談いただけます。
> 個別製品の仕様・対応可否、価格・在庫・納期は担当者が確認します。用途や必要な仕様、数量、ご希望の納期をお聞かせください。「担当者へのお問い合わせ」からもご相談いただけます。

質問: この一覧にない会社とは取引がない？

> ご案内している情報は取扱分野の一部です。掲載の有無から取引の有無や対応可否は判断できません。お探しの製品や用途をお知らせいただければ、担当者が確認します。

質問: 仕入先のHPを教えて

> 仕入・外注先の社名、ホームページ、取引の有無や取引条件は公開していません。お探しの製品や用途をお知らせください。取扱分野をご案内し、具体的な対応は担当者が確認します。

## 検証

| 対象                               | 結果                                                                                                        |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 実Excelを使った60項目              | 合格。45分野の検索、表記ゆれ、追加質問、未登録型番、再取込、永続化、利用停止を確認                          |
| 全41件の社名・HP・取引口座への質問 | 合格。社名だけの質問も含めて非公開の案内へ切り替え。レスポンス全体に社名・URL・元ファイル名がないことを検査 |
| 単体・結合テスト | 52件合格。短い会社名と社名の途中に法人表記がある場合の回帰テストを含む |
| PC・スマートフォンの画面テスト     | 取込・承認・公開回答・お問い合わせ送信・利用停止まで合格。既存の画面テストを含め16件合格                    |
| 型検査・本番用ビルド               | 合格                                                                                                        |

単体・結合テストでは、結合セル、表紙シート、5,000行を超える台帳からの抽出、ハイパーリンク、非表示行・シート、数式を実行しないこと、URL形式、不正な公開範囲指定、再取込での削除反映、短い会社名、資料内の指示文を回答に流さないことも確認している。

実データの検証では外部AI・Web検索を使用せず、ローカルの回答処理を検証した。将来追加される全ての商品名・言い換えへの対応を保証するものではない。公開する分野は定義済み語彙から選び、未知の分野は取込時に警告する。現在の定義は `lib/server/supplier-knowledge.ts` にある。

ビルドはサンドボックス内でTypeScriptの子プロセス起動がEPERMとなったため、許可された制限外実行で完了した。

## 再実行

```sh
node --import tsx scripts/verify-supplier-knowledge.ts '/path/to/仕入先一覧.xlsx'
```

独立した一時DBで検証し、非公開情報を除いた質問・期待する回答・実回答・合否を `.data/verification/supplier-knowledge-results.json` に出力する。`--register` を付けると検証合格後にアプリ用DBへ登録する。このスクリプトは今回の資料に含まれる代表分野の確認を含む。

元Excel、社名・HPを含む実データや認証情報をリポジトリへ追加していない。
